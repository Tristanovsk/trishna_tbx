# TRISHNA notebooks for the Water Quality VRE gallery

New entries for the gallery at https://ocean-and-coastal-water-quality-vre.netlify.app/gallery/.
They follow the gallery layout: Title / Requirements / Tutorial objectives / Environment /
Resources / Imports / numbered sections, plus *Data* (editable paths) and *Take-home messages*.
Kernel: `sandbox_env`, which also needs `trishna_tbx` (`pip install -e <path>/trishna_tbx`).

The notebooks are generated by `build_notebooks.py`. Edit that file, not the `.ipynb`:

```bash
python build_notebooks.py                 # write all notebooks
python build_notebooks.py --execute       # write and execute (keeps the outputs)
python build_notebooks.py --execute owt   # only the notebooks whose path contains "owt"
python build_notebooks.py --execute --allow-errors   # keep errors in the notebook (debugging)
python check_nb.py                        # executed cells / first error of each notebook
```

Cached results (GRS runs, datacube, emulated L1C) go to `<section>/output/`. Delete them to
force a recomputation.

Thumbnails for the gallery cards are written to `thumbnails/` when the notebooks run.
