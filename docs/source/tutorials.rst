Tutorials
=========

The tutorials are the TRISHNA notebooks of the
`Water Quality VRE gallery <https://ocean-and-coastal-water-quality-vre.netlify.app/>`__. They are
rendered with the outputs saved when they were last executed on the Magellium workstation; to run
them elsewhere, change the paths of their *Data* cell (see :doc:`usage`).
